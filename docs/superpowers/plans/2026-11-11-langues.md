# Six langues — plan de mise en œuvre

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** le site s'affiche en français, anglais, espagnol, chinois simplifié, hindi ou arabe : langue du navigateur si elle est l'une des six, sinon anglais ; changement manuel dans le pied de page.

**Architecture :** les textes quittent le code TypeScript pour des fichiers JSON par langue (lisibles tels quels par les futures apps Flutter). L'anglais est dans le script principal ; les autres langues sont des fichiers à empreinte chargés avec contrôle d'intégrité avant le premier affichage. Pluriels et formats passent par `Intl` ; l'arabe ajoute `dir="rtl"` et un CSS en propriétés logiques.

**Tech Stack :** Svelte 5, TypeScript, Vite 8 (greffon maison comme `shh-engine`), `Intl.PluralRules` / `Intl.NumberFormat` / `Intl.DateTimeFormat`, vitest, Playwright.

**Spec :** `docs/superpowers/specs/2026-11-11-langues-design.md` (et UI §10 de `2026-11-04-shhdrop-ui-design.md`).

## Global Constraints

- Langues et codes : `fr`, `en`, `es`, `zh`, `hi`, `ar` ; noms affichés : « Français », « English », « Español », « 中文 », « हिन्दी », « العربية ».
- Choix : première langue de `navigator.languages` dont la langue primaire (avant le premier `-`, en minuscules) est l'une des six ; sinon `en`. `zh-TW`, `zh-HK` → `zh`. Aucun fuseau horaire.
- Aucun stockage de la langue (ni `localStorage`, ni cookie) ; rien n'est envoyé au serveur.
- Source des textes : le français. Aucun texte français ou anglais existant ne change pendant la conversion.
- Chiffres occidentaux (0-9) dans toutes les langues (`numberingSystem: "latn"`).
- Aucune ressource tierce, aucune police externe (CLAUDE.md) ; fichiers de langue servis par le site, à empreinte, vérifiés (`integrity`).
- Jamais « 100 % sécurisé » ni d'équivalent dans aucune langue.
- Mots de passe, liens, noms de fichiers : toujours écrits de gauche à droite, même en arabe.
- Commits : `git commit --author="Skoow <190851638+Skoow@users.noreply.github.com>"`, lignes `Co-Authored-By` et `Claude-Session` ; tests verts avant chaque push ; tout sur `main`.
